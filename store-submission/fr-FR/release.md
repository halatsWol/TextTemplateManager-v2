### Nouveautés de cette version

#### Nouveau

- **Les données des versions plus récentes sont conservées :** les modèles et les dossiers gardent désormais ce qu'une version plus récente de TextTemplateManager y enregistre. Cette version ne supprime plus ces données à l'enregistrement, ni dans vos propres modèles ni dans les fichiers de synchronisation partagés.
- **Veuillez mettre à jour vers cette version chaque PC qui partage un fichier de synchronisation.** Les prochaines versions enregistreront davantage de données avec vos modèles, et les versions plus anciennes continuent de les supprimer.

#### Corrigé

- L'application s'ouvre de nouveau lorsqu'un fichier de synchronisation contient deux fois le même identifiant d'élément, par exemple après une fusion manuelle de copies en conflit. Jusqu'ici, elle restait sans fenêtre à partir du deuxième démarrage.
