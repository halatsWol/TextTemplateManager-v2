# Security policy

## Supported versions

Only the current release of TextTemplateManager 2 from the Microsoft Store gets security fixes. TextTemplateManager 1.x is no longer maintained.

## Reporting a vulnerability

Please report it privately, and don't open a public issue for it. Either way works:

- **On GitHub** (needs a GitHub account): on this repository's **Security** tab, choose **Report a vulnerability**.
- **By e-mail** (no account needed): write to [contact@kmarflow.com](mailto:contact@kmarflow.com?subject=TextTemplateManager%3A%20security%20vulnerability&body=App%20version%20%28Help%20%3E%20About%29%3A%0D%0AWindows%20version%3A%0D%0A%0D%0AWhat%20is%20affected%3F%0D%0A%0D%0AHow%20to%20reproduce%20it%2C%20step%20by%20step%3A%0D%0A1.%0D%0A2.%0D%0A3.%0D%0A%0D%0AWhat%20can%20an%20attacker%20do%20with%20it%3F%0D%0A) with the subject "TextTemplateManager: security vulnerability".

Please include the version (Help ▸ About), what is affected and how to reproduce it. A fix ships as a Store update, and the advisory is published once the update is out.
