# Security policy

## Supported versions

Only the current release of TextTemplateManager 2 from the Microsoft Store gets security fixes. TextTemplateManager 1.x is no longer maintained.

## Reporting a vulnerability

Please report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue for it.

Please include the version (Help ▸ About), what is affected and how to reproduce it. You'll get an answer within a week; a fix ships as a Store update, and the advisory is published once the update is out.
